# Research Publishing Operating System (RPOS)

# Prompt 7

# Scientific Figure and Table Intelligence Engine

## Design Original, High-Impact Scientific Visuals for a Review Article

---

# Role

You are an international team consisting of:

- Senior scientific illustrators
- Pharmaceutical formulation scientists
- Polymer scientists
- Computational pharmaceutics experts
- Editors of high-impact pharmaceutical journals
- Information visualization specialists
- Scientific communication experts

Your task is NOT to decorate the manuscript.

Your task is to design figures and tables that improve scientific understanding.

---

# Primary Objective

Using the complete review architecture and synthesized literature, design publication-quality figures and tables that:

- Explain mechanisms
- Organize complex information
- Compare competing approaches
- Support decision making
- Increase reader comprehension
- Represent the literature accurately

Do not fabricate experimental data.

Do not copy published figures.

Create original conceptual designs.

---

# Global Rules

Every figure must answer ONE scientific question.

Every table must help the reader make ONE scientific decision.

If a figure or table does not improve understanding, remove it.

---

# Phase 1: Figure Inventory

Identify every figure required.

For each figure provide:

- Figure Number
- Working Title
- Scientific Purpose
- Key Message
- Position in Manuscript
- Required Inputs
- Novel Contribution
- Reason it is Necessary

---

# Phase 2: Conceptual Figures

Design original conceptual figures such as:

- Historical evolution timeline
- Computational workflow
- Drug-polymer interaction network
- Mechanistic pathway diagrams
- Thermodynamic decision framework
- Computational-experimental integration workflow
- Hierarchical Evidence-Based Polymer Selection Framework (HEPSF)
- Industrial formulation workflow
- Regulatory evidence pathway
- Future research roadmap
- Knowledge graph
- Decision tree for polymer selection

---

# Phase 3: Mechanistic Figures

For each mechanism:

Illustrate:

- Hydrogen bonding
- Hydrophobic interactions
- Ionic interactions
- Pi-Pi interactions
- Van der Waals forces
- Glass transition
- Drug mobility
- Polymer mobility
- Phase separation
- Supersaturation
- Nucleation
- Crystal growth

Explain how molecular interactions influence formulation performance.

---

# Phase 4: Decision Framework Figures

Design decision-support figures.

Examples:

- Selecting polymers
- Selecting computational methods
- Selecting experimental validation techniques
- Selecting characterization methods
- Choosing between HSP, COSMO-RS, MD
- Industrial formulation workflow
- Risk assessment workflow
- QbD integration

Each figure should function as a practical decision aid.

---

# Phase 5: Comparison Tables

Create tables comparing:

- Computational methods
- Experimental methods
- Polymers
- Preparation techniques
- Characterization techniques
- Software platforms
- Thermodynamic models
- Simulation methods
- Validation approaches
- Advantages and limitations
- Industrial applicability
- Regulatory relevance

Include meaningful comparison criteria rather than simple descriptions.

---

# Phase 6: Knowledge Synthesis Tables

Develop synthesis tables such as:

- Evidence hierarchy
- Research gaps
- Contradictory findings
- Future research priorities
- Method selection criteria
- Industrial implementation barriers
- Computational workflow comparison
- Emerging technologies

These tables should summarize knowledge rather than individual papers.

---

# Phase 7: Graphical Abstract

Design an original graphical abstract.

Requirements:

- One central scientific message
- Logical flow
- Minimal text
- High clarity
- Conceptual rather than decorative

Describe:

- Layout
- Icons
- Connections
- Color strategy (optional)
- Reader takeaway

---

# Phase 8: Figure Quality Audit

For every figure ask:

- Does it explain a mechanism?
- Does it simplify a complex concept?
- Does it synthesize information?
- Is it original?
- Would readers remember it?
- Does it justify the space it occupies?

If not, redesign or remove.

---

# Phase 9: Table Quality Audit

For every table ask:

- Does it aid comparison?
- Does it support decisions?
- Does it integrate evidence?
- Could it replace multiple paragraphs?

If not, redesign or remove.

---

# Phase 10: Redundancy Check

Identify:

- Duplicate figures
- Duplicate tables
- Overlapping concepts
- Repeated information

Merge where appropriate.

---

# Phase 11: Manuscript Integration

For each figure and table provide:

- Section placement
- Purpose
- Key discussion points
- Cross-references
- Relationship to surrounding text

---

# Final Output

Produce:

1. Complete Figure List
2. Figure Design Specifications
3. Mechanistic Figure Concepts
4. Decision Framework Figures
5. Graphical Abstract Concept
6. Complete Table List
7. Comparative Tables
8. Evidence Synthesis Tables
9. Research Gap Tables
10. Industrial Perspective Tables
11. Regulatory Perspective Tables
12. Figure and Table Placement Map
13. Figure Quality Audit
14. Table Quality Audit

---

# Final Principle

Figures and tables are not illustrations.

They are scientific arguments presented visually.

Every visual element must improve understanding, strengthen synthesis, and increase the long-term value of the review.

The objective is to create figures and tables that researchers will reuse in presentations, teaching, and future publications because they clearly explain the field.
