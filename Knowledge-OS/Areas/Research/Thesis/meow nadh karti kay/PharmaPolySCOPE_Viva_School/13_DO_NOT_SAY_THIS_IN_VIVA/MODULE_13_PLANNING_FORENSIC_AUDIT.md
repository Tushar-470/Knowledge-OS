## 4. Six-Tier Epistemic Classification Audit

The proposed classification system was audited to detect category confusion, tier overlap, and promotion risks:

```
+-----------------------------------------------------------------------------------------+
|                               EPISTEMIC TIER DEFINITIONS                                |
+--------+---------------------------------------+----------------------------------------+
| Tier   | Designation                           | Epistemic Scope                        |
+--------+---------------------------------------+----------------------------------------+
| TIER-1 | Directly Established by Implementation| Hard-coded constants, code ASTs, errors|
| TIER-2 | Established by Numerical Computation  | Exact calculated outputs (eigenvalues) |
| TIER-3 | Supported as Methodological Diagnostic| Computational proxy indicators (HSP)   |
| TIER-4 | General Scientific Interpretation     | Physical chemistry literature theory   |
| TIER-5 | Experimentally Unvalidated            | Physical laboratory properties (shelf) |
| TIER-6 | Explicitly Outside Model Scope        | Clinical PK/PD, manufacturing defects  |
+--------+---------------------------------------+----------------------------------------+
```

### Forensic Review of Tiers & Controls
1. **Tier Overlap & Disambiguation (Tier 2 vs. Tier 3):**  
   *Audit Finding:* A raw calculated number (e.g., $s_{\text{HSP}} = 0.7225$) belongs to **Tier 2** (exact numerical output). However, using that number to evaluate compatibility belongs to **Tier 3** (methodological diagnostic).  
   *Enforced Rule:* The delivery must never conflate the calculation of a number with its scientific diagnostic interpretation.
2. **The Anti-Promotion Barrier (Tier 3 -> Tier 5):**  
   *Audit Finding:* The most lethal viva error is promoting a Tier-3 methodological indicator (e.g., high Gordon-Taylor score $s_{\text{GT}}$) into a Tier-5 physical reality (e.g., "the formulation will not crystallize for 2 years").  
   *Enforced Rule:* Every Tier-3 replacement statement must include an explicit clause barring promotion to Tier 5.
3. **Reference Input Data Nuance:**  
   *Audit Finding:* Literature input constants (such as Indomethacin $T_g = 315.15\text{ K}$ or polymer library structures) are neither AST constants (Tier 1) nor calculated outputs (Tier 2).  
   *Refinement:* They are categorized as **Curated Reference Inputs** within Tier 1, grounded in immutable configuration CSVs.
